Privacy Policy

Last updated: August 2026

1. Introduction

Planis (“the app”, “we”) is a mobile application for personal travel tracking. This Privacy Policy describes how the app handles users’ information.

2. Data collection

Planis does not collect, transmit or share any personal data with external servers or third parties.

All data entered by the user (trips, stops, favorite cities, notes, preferences) is stored exclusively on the user’s local device, inside the app’s private database.

3. Data stored locally

The app stores the following information on the device, voluntarily provided by the user:

  • Trips and stops (cities, dates, means of transport, notes)
  • Favorite cities
  • City of residence
  • App preferences (language, theme, color)

This data never leaves the user’s device, unless the user explicitly exports it (see section 5).

4. Data not collected

Planis does not collect and has no access to:

  • Name, email or any identifying data
  • Real-time GPS location
  • Usage data or analytics
  • Crash or diagnostic data
  • Advertising identifiers
  • Contacts, camera, microphone or other device resources

5. Data export

The app offers an export feature that lets the user save their data to a JSON file on their own device. This operation is entirely under the user’s control — the app never sends data anywhere automatically.

6. Data deletion

The user can delete all data saved by the app at any time using the “Delete all data” function in the app’s Settings section. Uninstalling the app automatically removes all local data from the device.

7. Internet connection

The app requests Internet access permission exclusively to load the cartographic data needed for the map to work. No personal user data is transmitted during this operation.

8. Security

Since all data remains on the local device, data security depends on the security of the user’s device (e.g. screen lock, device encryption).

9. Children’s privacy

Planis is not intended for users under the age of 13 and does not knowingly collect data from minors.

10. Changes to this policy

Any changes to this policy will be communicated through an app update. The “Last updated” date at the top of the document will be updated accordingly.

11. Contact

For questions or requests about privacy, you can contact us at: r.zero.developer@gmail.com
